Aquesta acció desa el canvi a GitHub (PAGEWEB01), però no publica. Després, prem «Actualitzar tota la Preview» per aplicar els canvis de plantilla a totes les rutes publicades.

Publicació a Vercel Preview

La publicació és sempre manual. Els commits a GitHub no despleguen res automàticament.

Un sol clic reconstrueix PAGEWEB01 i actualitza la Preview compartida perquè totes les rutes publicades utilitzin la nova versió de la plantilla. Només Preview, mai Production.

Per afegir una pàgina nova al conjunt publicat, utilitza «Publicar a Preview» a la fila d'aquella pàgina. Les altres rutes publicades també queden actualitzades en aquest mateix deployment.

Què mostra aquest editor

  • Pàgines obtingudes de l'arbre real de GitHub, no d'una llista fixa.
  • Plantilles declarades a web/data/page-editor.json i registres de pàgines.
  • Enllaços a totes les rutes de pàgina sobre el deployment Preview base registrat, i acció per publicar/actualitzar manualment cada pàgina.
  • Publicació només mitjançant el workflow manual de GitHub Actions.

L'esborrat elimina definitivament el fitxer seleccionat de PAGEWEB01 després de confirmar-ho; no es pot desfer des d'aquest editor.
