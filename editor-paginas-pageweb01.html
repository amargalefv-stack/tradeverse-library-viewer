Publicació a Vercel Preview

La publicació és sempre manual. El botó obre el flux de GitHub Actions per publicar la branca a Preview; no es desplega l’editor a Vercel.

En obrir el flux, prem «Run workflow» i introdueix la ruta de la pàgina seleccionada. El workflow publica la branca a Preview, no a Production.

Obrir flux de publicació

Què mostra aquest editor

  • Pàgines obtingudes de l'arbre real de GitHub, no d'una llista fixa.
  • Plantilles declarades a web/data/page-editor.json i registres de pàgines.
  • Enllaços al codi de cada pàgina i a la seva ruta de Preview quan es pot verificar.
  • Publicació només mitjançant el workflow manual de GitHub Actions.

L'editor és de lectura per a GitHub. No modifica ni esborra fitxers de la branca.

Font de dades: GitHub API · amargalefv-stack/tradeverse-project-master · PAGEWEB01. Si la branca és privada o l'API no està disponible, es mostrarà l'error en lloc d'inventar dades.
